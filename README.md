# test-cricket-analysis
# Analyzing Virat Kohli's Test Cricket Career

## Overview

This project analyzes Virat Kohli's Test batting career using
ball-by-ball data from Cricsheet.

The analysis examines:
- Batting average by year
- Changes in batting performance across career periods
- Dismissal types across career periods

## Tools

- Python
- pandas
- NumPy
- Matplotlib

## Data

The data comes from Cricsheet's Test match ball-by-ball datasets.

## Main Findings

The analysis shows how Kohli's batting average changed over time
and compares the frequency of different dismissal types across
three career periods.

## Limitations

The analysis describes patterns in the available data. It does
not establish why Kohli's performance changed or which specific
bowling strategies caused his dismissals.
